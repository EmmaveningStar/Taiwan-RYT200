# Google 表單審核同步

目前網站投稿入口已接到公開 Google 表單。Google 回覆同步需完成以下設定，未設定前不會讀取表單回覆。

1. 在表單「回覆」分頁建立／連結 Google 試算表。保留試算表的限制存取權，不要發布整張回覆表。
2. 試算表「擴充功能 → Apps Script」貼上 scripts/google-form-approval.gs。
3. 執行 setupApprovalSheet，使用表單擁有者帳號授權。程式會加入「審核狀態」欄。
4. 部署為網頁應用程式，以自己身分執行、允許任何人存取。這個端點只公開已核准列的主辦教室／老師、縣市、投稿內容及相關連結；未核准列與其他欄位不會輸出。部署前核對已核准內容可公開。
5. 將部署的 /exec URL 加到 GitHub repository secret：GOOGLE_APPROVED_FEED_URL。
6. 執行 Actions「更新課程網站」。檢查流程成功，再核對網站讀者分享。

在試算表將「審核狀態」設為「已核准」才會公開；空白、「待審核」、「不公開」不會公開。
移除核准後，下次成功部署會撤下該筆。網站每日台灣時間 07:23 排程更新，GitHub 排程可能延後；需要立即更新可手動 Run workflow。
核准來源故障會停止部署，保留先前版本，不會假裝同步成功。
這些回覆顯示於「讀者分享」，不會自動當成已核實的正式課程。

# 全台課程搜尋

必須另設 BRAVE_SEARCH_API_KEY 才能自動搜尋。金鑰未設定時，程式會在部署紀錄明確說明略過搜尋。
目前搜尋查詢涵蓋台灣各區及公開 Facebook、Threads 索引，輸出候選於 course-source-review 附件。
候選不是已核對課程，不會直接寫入正式列表。正式列表仍來自 data.json 與核准且欄位完整的 GitHub 課程投稿。
公開搜尋索引無法保證全台完整覆蓋；需要持續核對候選來源並補入課程資料。
